# 评分与分级

每条收录的内容由 DeepSeek 按**五维评分**给出 0-100 分，再分级（A/B/C），并决定是否启动间隔复习。

**核心设计**：评分 prompt 固化在脚本里，Agent 不参与打分。否则 Agent 会"看心情发挥"。

---

## 五维评分

每维 0-25 分，总分 0-100。

| 维度 | 25 分含义 | 0 分含义 |
|------|---------|---------|
| **density**（信息密度）| 单位篇幅干货密集 | 全是水话/凑字数 |
| **actionable**（可操作性）| 明确告诉你下一步怎么动手 | 纯感想没法落地 |
| **uniqueness**（观点独特）| 独家视角/新角度 | 烂大街/到处都有 |
| **reliability**（可靠性）| 权威+扎实论据 | 自媒体复读/无来源 |
| **reusability**（复用价值）| 一年后回看还有用 | 3 天就过期 |

### 评分原则（写在 prompt 里）

```
- 敢给低分，不要全 18-22
- 信息密度差的就给 5-10 分
- 给分前先思考亮点和弱点，再下笔
- 总分必须 = 五维之和
```

### 实际效果

| 内容 | 分数 | tier | 说明 |
|------|------|------|------|
| 麦冬AI"Hermes 记忆四层架构详解" | 95 | A | 密度 20, 独特 18（架构图清晰）, 复用 20（长期价值高）|
| 麦冬AI"Hermes 多实例 profile 教程" | 60 | C | 密度 12（口语化重复）, 可靠 5（无论据）|

注意：**同一作者不同视频可以打出 95 / 60 的巨大差距**，证明评分维度真的在起作用、不靠"作者人设"加权。

## Tier 阈值

```python
tier = "A" if score_total >= 90 else ("B" if score_total >= 80 else "C")
```

| Tier | 分数 | 处理 |
|------|------|------|
| **A** | ≥ 90 | 精华（按原文 18%）+ **启动间隔复习** + 完整原文保留 |
| **B** | 80-89 | 精华（按原文 18%）+ 不启动复习 + 完整原文保留 |
| **C** | < 80 | 精华（按原文 18%）+ 不启动复习 + 完整原文保留 |

> ⚠️ 当前实现下，**C 级也保留原文**（统一保留）。设计上是为了"以后改主意了能复盘"。
>
> 想手动提级让 C 也启动复习？用 `digest promote <id>` 命令，详见 [[08-命令速查]]。

## Weight（权重）

`weight` 字段初始 = `score_total`，是一个 0-100 的检索/排序权重。

**当前实现**：写入时就是 score_total，**没有动态调整逻辑**。

**未来扩展**（TODO）：
- 用户主动操作（pin / archive） → ±20
- 被引用 / 被检索点击 → +5
- 长期未复习 → 衰减

## 精华字数（**2026-05-13 改造**：从固定 → 动态）

### 之前的设计（已废弃）

```python
# 旧版本
ESSENCE_CHARS = {"A": 400, "B": 200, "C": 100}
```

**问题**：用户给了 8 千字视频，C 级只摘 100 字 → 看了等于没看，**没有"省去看视频"的效果**。
tier 反映的是"质量评分"，不是"内容长度"——即使 C 级内容也要充分覆盖要点。

### 现在的设计（2026-05-13 起）

```python
# essence.py
def calc_target_chars(content_chars: int) -> int:
    """精华目标字数 = 内容 × 18%，下限 300，上限 1800。"""
    raw = int(content_chars * 0.18)
    return max(300, min(1800, raw))
```

### 字数与原文长度对照

| 原文字数 | 精华字数（18%）| 实际下限/上限 |
|---------|--------------|-------------|
| 500 字（短文章）| 90 字 | **300 字**（下限兜底）|
| 1500 字（短视频文案）| 270 字 | **300 字**（下限兜底）|
| 3000 字（中等视频）| 540 字 | 540 字 |
| 8000 字（长视频）| 1440 字 | 1440 字 |
| 15000 字（长文章）| 2700 字 | **1800 字**（上限封顶）|

实际验证（id=5，3168 字量化视频）：

```
target: 570 字
actual: 981 字  ← LLM 觉得内容有料，多写了 70%（允许的）
```

### 精华结构（写在 prompt 里）

```
## 🎯 核心论点          (1-2 句话讲清作者中心观点)
## 📚 关键论证 / 步骤 / 例子   (主体，分点详细)
## ⚙️ 具体方法 / 工具 / 代码   (原样保留命令、参数、工具名)
## ✨ 金句 / 强调点      (作者反复提及的)
## ⚠️ 局限 / 弱点       (1-2 句让主人有判断)
```

每个小节可省略，但 LLM 会按这个骨架组织——这样**主人读起来定位重点很快**。

### 写作目标（prompt 强约束）

> 读者读完你的精华后，**应该获得 80% 看完原视频的价值，不需要再回去看视频**。

如果内容真水（重复、口语化、没具体方法），允许 LLM 直接说"作者大多在反复讲 X 观点，没有给出具体方法。要点：A、B"就够了，**不准凑字数**。

详见 [[02-Ingest-Pipeline#Step 4 essence]]。

## 给主人的回复格式（**2026-05-13 改造**：加入完整精华）

Step 5 save 生成的 `summary_for_agent`，飞书会直接展示给主人。

**之前**：只有评分 + 反思问题，主人看不到精华本身，必须打开 md 文件才能看。
**现在**：完整精华嵌在飞书消息里，主人不用打开 Obsidian 也能消化。

```
📌 一句话核心
🏷 #tag1 #tag2 #tag3

━━━━━━━━━━━━━━━━━━

- **多时间周期**：观察 15/30/60 分钟周期的资金流向
```

## 复习启动条件

```python
review_enabled = 1 if score_total >= 90 else 0
if review_enabled:
    next_review_at = pipeline_io.add_days(1)  # 北京时间 + 1 天
```

只有 tier A 才进复习队列。B/C 归入知识库不主动催。

详见 [[06-复习系统]]。

## 评分 Prompt 节选

```
请对以下内容做五维评分。每维 0-25 分（总分 0-100）。

返回 JSON 格式：
{
  "scores": {"density": N, "actionable": N, "uniqueness": N, "reliability": N, "reusability": N},
  "total": N,
  "tier": "A" | "B" | "C",
  "rationale": {"strength": "一两句话总结亮点", "weakness": "一两句话总结弱点"}
}

tier 规则：>=90 是 A，80-89 是 B，<80 是 C。

待评内容：
标题：{title}
作者：{uploader}
平台：{platform}
正文/转录（{content_chars} 字）：
<<<
{content}
>>>
```

完整 prompt 在 `score.py` 的 `USER_PROMPT_TEMPLATE`。

## 调整空间

| 想改什么 | 改哪 |
|---------|------|
| 五维定义 / 评分原则 | `score.py` 的 `USER_PROMPT_TEMPLATE` |
| tier 阈值 (90/80) | `score.py` 末尾的判断逻辑 + `save.py` |
| 精华字数 | `essence.py` 的 `calc_target_chars()` 函数（默认 18%、下限 300、上限 1800）|
| 精华结构 / 写作目标 | `essence.py` 的 `PROMPT_TEMPLATE` |
| 复习启动条件 | `save.py` 的 `review_enabled = 1 if score_total >= 90` |
| Temperature（评分稳定性）| `pipeline_io.call_deepseek(..., temperature=0.0)` |
| 手动改 tier | `digest promote <id>` / `digest demote <id>` / `digest demote <id> --archive` |
