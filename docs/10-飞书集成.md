# 飞书集成

知识助手通过飞书机器人对外。两类通信：
1. **入站**：用户 → 飞书 Bot → Hermes Gateway → Agent（WebSocket 长连接）
2. **出站**：Cron / Agent → 飞书 OpenAPI → 用户

## 入站：用户 → Agent

### 链路

```
用户在飞书 APP 给"知识学习助手"发消息
   ↓
飞书后台
   ↓ WebSocket (msg-frontier.feishu.cn)
Hermes Gateway (knowledge profile, systemd)
   ↓ 解析消息
   ├─ 检查白名单（FEISHU_ALLOWED_USERS）
   ├─ 检查 pairing/feishu-approved.json
   └─ 找到 chat_id → 唤起 Agent 处理
   ↓
Agent 按 SOUL.md 规则处理 → 调 terminal 等工具
   ↓
Agent 输出 → Hermes Gateway → 飞书 OpenAPI 回复消息
```

### 用户 open_id 识别

**重要**：同一个微信号在不同飞书 App 下 open_id 不同！

| App | 用户在该 App 下的 open_id |
|-----|---------------------|
| 量化助手 App | `ou_32deed2368399d59541751667cab93e9` |
| **知识助手 App（本项目）** | `ou_edf99c843d614af252238810fbbf0697` |

获取方式：看 `/root/.hermes/profiles/knowledge/logs/agent.log`，每条 inbound message 会打印 `user=ou_xxx`。

### Chat ID

```
oc_405f09b60458dab012b7364067af6f74
```

**Chat ID ≠ Open ID**：
- `oc_` 开头：聊天会话 ID（私聊或群聊）
- `ou_` 开头：用户 ID

私聊场景下，open_id 就足以定位用户；chat_id 用来判断"这条消息发往哪个对话框"。

## 出站：Cron / Agent → 用户

**Cron 主动推送**用飞书 OpenAPI 直推（绕开 Hermes Gateway）。**Agent 回复消息**走 Hermes Gateway 的内置发送逻辑。

### OpenAPI 直推

实现：`/root/.hermes/profiles/knowledge/skills/_lib/review_pusher.py`

#### Step 1：拿 tenant_access_token

```python
POST https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal
body: {"app_id": "cli_aa8a79adf9b8dccc", "app_secret": "..."}

→ {"code": 0, "tenant_access_token": "t-xxx", "expire": 7200}
```

token 2 小时有效。简单起见每次都刷（不缓存，避免引入状态）。

#### Step 2：发文本消息

```python
POST https://open.feishu.cn/open-apis/im/v1/messages?receive_id_type=open_id
header: Authorization: Bearer <token>
        Content-Type: application/json; charset=utf-8
body: {
  "receive_id": "ou_edf99c843d614af252238810fbbf0697",
  "msg_type": "text",
  "content": "{\"text\": \"复习题文字...\"}"
}
```

**注意 `content` 字段是 JSON-stringify 的字符串**，不是嵌套 JSON。文本里 `\n` 转义成换行。

#### Python 实现

```python
import httpx, json

def send_to_feishu(text: str) -> bool:
    app_id, app_secret = read_feishu_creds()
    token = get_tenant_token(app_id, app_secret)
    r = httpx.post(
        "https://open.feishu.cn/open-apis/im/v1/messages",
        params={"receive_id_type": "open_id"},
        headers={"Authorization": f"Bearer {token}"},
        json={
            "receive_id": FEISHU_OPEN_ID,
            "msg_type": "text",
            "content": json.dumps({"text": text}, ensure_ascii=False),
        },
        timeout=15,
    )
    return r.status_code == 200 and r.json().get("code") == 0
```

## 故障排查

### 「Bot 没回复」

```bash
# 1. 服务活着吗
systemctl --user is-active hermes-gateway-knowledge

# 2. 看实时日志
journalctl --user -u hermes-gateway-knowledge -f

# 3. 看飞书连接状态
journalctl --user -u hermes-gateway-knowledge -n 100 | grep -i feishu

# 应该看到：
# [Feishu] Connected in websocket mode
# Inbound dm message received: text='...'
# response ready: ... chars
```

### 「推送没收到」

```bash
# 1. 手动跑一次看错误
review-push
# 注意 stderr 输出

# 2. 看 cron 日志
tail /var/log/review_pusher.log

# 3. 测最简推送
/www/content_fetcher_venv/bin/python -c "
import sys
sys.path.insert(0, '/root/.hermes/profiles/knowledge/skills/_lib')
import review_pusher
print(review_pusher.send_to_feishu('test'))
"
```

### 「飞书报 401 / token invalid」

App Secret 改过？重新去飞书后台拿，更新 `.env`：

```bash
nano /root/.hermes/profiles/knowledge/.env
# 改 FEISHU_APP_SECRET=
systemctl --user restart hermes-gateway-knowledge
```

### 「用户不在白名单」

日志会显示：
```
[Feishu] Rejected message from ou_xxx (not in FEISHU_ALLOWED_USERS)
```

把这个 `ou_xxx` 加进 `.env` 的 `FEISHU_ALLOWED_USERS`。

或者更新 `/root/.hermes/profiles/knowledge/pairing/feishu-approved.json`：

```json
{
  "ou_edf99c843d614af252238810fbbf0697": {
    "user_name": "王竞辉",
    "approved_at": 1778510000.0
  }
}
```

## 限流

飞书 OpenAPI 发消息默认配额：**每个机器人每分钟 1000 条**。我们的场景一天最多几条推送，完全用不到上限。
