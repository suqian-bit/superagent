## 用户命令（短链 in `/usr/local/bin/`）

所有 wrapper 都跑在 `/www/content_fetcher_venv/bin/python` 这个独立 venv 下（避免污染系统 / Hermes 自己的 venv）。

| 命令 | 用途 | 用法 |
|------|------|------|
| `xhs` | Pipeline Step 1，抓小红书 | `xhs "<URL>" --transcribe` |
| `video` | Pipeline Step 1，抓视频平台 | `video "<URL>"` |
| `text` | **Pipeline Step 1，纯文本入库**（无 URL）| `text --title "..." --content "..." [--source douyin]` 或 `... --from-stdin` |
| `ocr` | **图片转文字**（RapidOCR ONNX，本地）| `ocr img.png` 或 `ocr img1.png img2.png ... --text-only` |
| `ocr-stash` | **多张截图聚合 → 一次性入库**（飞书一次一张图场景）| `ocr-stash add/status/preview/commit/clear/expire-check` |
| `fetch-feishu-image` | 从飞书消息下载图片到本地 | `fetch-feishu-image <message_id> <image_key> [--output /tmp/x.png]` |
| `score` | Pipeline Step 2，五维评分 | `score --in /tmp/ingest/..._step1.json` |
| `classify` | Pipeline Step 3，分类+标签+指纹 | `classify --in /tmp/ingest/..._step2.json` |
| `essence` | Pipeline Step 4，**动态字数（原文 18%）** 精华 | `essence --in /tmp/ingest/..._step3.json` |
| `save` | Pipeline Step 5，落盘 md + SQLite | `save --in /tmp/ingest/..._step4.json` |
| `digest` | 查询 + 复习反馈 + **手动调级** + **场景化检索** | `digest <subcmd>`（见下）|
| `project` | **项目档案管理**（2026-05-14 新增）| `project <subcmd>`（见下） |
| `review-push` | 复习推送（cron 用，**没 due 时早 9 点推心跳**）| `review-push`（无参数）|
| `weekly-report` | 周报推送（cron 用）| `weekly-report [--dry-run] [--force]` |
| `detect-share` | **识别分享口令格式**（没 URL 但像口令时调）| `detect-share "<文本>"` |

### `digest` 子命令

#### 查询类

```bash
digest stats                     # 全库统计：总数、tier 分布、平台、due 数、top tags...
digest list [--limit 20]         # 最近收录
digest by-tag <tag>              # 按标签找
digest by-cat <cat> [--min-affinity 50]  # 按分类找（默认 affinity ≥ 50）
digest find <fingerprint>        # 精确指纹查
digest view <id>                 # 看一条详细（含全字段 + tags/categories）
```

#### 复习反馈类

```bash
digest due [--limit 5]           # 今天该推的（cron 用 / 手动看）
digest pending-review            # 最近 24h 推过但未答的复习（agent 用来识别用户回复）
digest review <id> <q1-5>        # SM-2 更新（agent 自动调 / 手动也行）
```

#### 场景化检索类（**2026-05-14 新增**）

```bash
digest impact "<场景的自然语言>"   # 主人卡住时翻库找相关内容
```

会自动：
1. LLM 拆关键词 + 识别匹配项目
2. 综合 item_projects 关联 + 关键词 LIKE 搜
3. 返回 Top 8 + 推荐使用方式

示例：
```bash
digest impact "我现在要给 momentum 策略加多时间周期"
# {"matched_project": "quant", "keywords": ["动量策略","多时间周期","回测"],
#  "results": [{id=5, score=...}, ...]}
```

### `project` 子命令（**2026-05-14 新增**）

```bash
project questions                # 拿引导问题清单（agent 建新档案前调）
project list [--all]             # 看所有项目（--all 含 archived）
project show <name>              # 看某项目档案 + 关联 items
project new <name> '<json>'      # 建新档案（自动反扫老库存）
project new <name> -             # 从 stdin 读 JSON
project new <name> '<json>' --no-backscan   # 跳过反扫

project update <name> --section pain_points --text "新卡点 XX" --mode append
                                 # 增量更新某段
                                 # section: goal/progress/pain_points/code_location/tags/cadence/notes
                                 # mode: append（追加）/ replace（替换段落内容）

project link <item_id> <name> <relevance> [--reason "..."]
                                 # 手动关联 item ↔ project
project unlink <item_id> <name>
project relevance <item_id>      # 看一条 item 关联了哪些 project

project archive <name> [--status done/paused]
```

完整设计 + 引导问答机制详见 [[12-项目档案与关联]]。

#### 手动调级类（**2026-05-13 新增**）

```bash
digest promote <id>              # 默认推到 A 级 + 启动复习（明天开始）
digest promote <id> --tier B     # 推到指定 tier
digest promote <id> --weight 88  # 同时调权重

digest demote <id>               # 默认推到 C 级 + 停止推送
digest demote <id> --tier B      # 降到 B 但保留复习
digest demote <id> --archive     # 彻底归档（查询/推送都看不到）
```

主人在飞书直接说"这条提到 A"、"降到 C"、"归档"，Agent 会自动调对应命令（SOUL.md 已写规则）。

### 实例

```bash
# 看库存
digest stats
# {"total": 5, "by_tier": {"A": 4, "C": 1}, "by_platform": {...}, ...}

# 看今天该复习啥
digest due
# {"count": 1, "items": [...]}

# 看最近 10 条
digest list --limit 10

# 找 AI 类下高关联度的
digest by-cat AI --min-affinity 80

# 手动答一条复习
digest review 3 4

# 看 id=5 详情
digest view 5

# 把 id=5 提到 A 级（启动复习）
digest promote 5

# 把 id=2 归档
digest demote 2 --archive

# 周报手动跑（已发过本周就 skip）
weekly-report

# 周报预览（不推）
weekly-report --dry-run

# 强制重发周报
weekly-report --force
```

## SQLite 直查

```bash
sqlite3 /www/knowledge/index.db

-- 全部 item
SELECT id, tier, score_total, fingerprint, title FROM items ORDER BY id DESC;

-- 该复习的
SELECT id, title, tier, next_review_at, review_count, mastery
FROM items WHERE review_enabled=1 AND archived=0
ORDER BY next_review_at ASC;

-- 推送历史最近 10
SELECT id, item_id, mode, pushed_at, response_quality
FROM push_history ORDER BY id DESC LIMIT 10;

-- 标签云
SELECT name, count FROM tags ORDER BY count DESC LIMIT 20;

-- 分类
SELECT name, count FROM categories ORDER BY count DESC;

-- 看某 item 详情
SELECT * FROM items WHERE id=3;
```
