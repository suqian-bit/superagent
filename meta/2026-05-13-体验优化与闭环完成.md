# 2026-05-13 · 体验优化与闭环完成

> 这一天补齐了主线闭环最后一环，并解决了"精华太少看不到视频价值"的核心体验问题。
> 至此项目从"能跑通"进入"真的好用"。

---

## 核心动作

### 1. 精华字数：固定 → 动态（最重要的体验改造）

**用户原话**：
> "我发现一个问题，我给他的视频，他可以给我返回，但是整理总结的内容偏少，我是希望，给他视频，他把核心内容给我返回，让我省去了自己看视频理解的过程"

**根因**：之前用 `ESSENCE_CHARS = {"A": 400, "B": 200, "C": 100}` 固定字数，C 级只摘 100 字 → 8 千字视频被压缩到 100 字 → 等于没看。

**改造**：

```python
def calc_target_chars(content_chars: int) -> int:
    """精华目标字数 = 内容 × 18%，下限 300，上限 1800。"""
    raw = int(content_chars * 0.18)
    return max(300, min(1800, raw))
```

**prompt 改造**——从"提炼"改为"重述给没看过的人"：

> 读者读完你的精华后，应该获得 80% 看完原视频的价值，不需要再回去看视频。
>
> 如果内容真水（重复、口语化、没具体方法），不要凑字数——
> 直接写"作者大多在反复讲 X 观点，没有给出具体方法。要点：A、B"就够了。

**强制结构**：

```
## 🎯 核心论点         （1-2 句作者中心观点）
## 📚 关键论证 / 步骤 / 例子  （主体，分点详细）
## ⚙️ 具体方法 / 工具 / 代码  （原样保留命令、参数）
## ✨ 金句 / 强调点      （作者反复提及的）
## ⚠️ 局限 / 弱点        （让主人有判断）
```

**实测效果**（id=5，3168 字量化视频）：

| | 旧 essence | 新 essence |
|--|----------|----------|
| 字数 | ~100 字 | **981 字**（target 570，多写 70%）|
| 结构 | 一两段，无小节 | **5 个小节**（核心 / 论证 / 方法 / 金句 / 局限）|
| 具体方法 | ❌ | ✅（T-MAX 框架 / 资源红线 / 训练配置）|
| 金句 | ❌ | ✅（"宁可不交易"等 3 句）|
| 标注局限 | ❌ | ✅（4 条说哪里不够）|

详见 [[../docs/03-评分与分级#精华字数]]。

### 2. summary_for_agent 注入完整精华

之前飞书消息只发：评分 + 反思问题，**主人看不到精华本身**——必须打开 Obsidian / md 文件才能看到。

现在飞书消息直接包含完整精华（981 字结构化），主人**不用打开任何外部工具就能消化**：

```
📌 一句话核心
🏷 #tag1 #tag2 #tag3
📂 AI(95) / 投资(85)

━━━━━━━━━━━━━━━━━━
💎 精华（981 字，原文 3168 字）
━━━━━━━━━━━━━━━━━━
（5 个小节的 markdown 精华）
━━━━━━━━━━━━━━━━━━
📊 评分：40/100 (C 级)
   密度12 / 可操作5 / 独特8 / 可靠5 / 复用10

🧠 反思 3 问：
  1. ...
  2. ...
  3. ...

🔁 归入知识库
```

实现在 `save.py` 的 `summary_for_agent` 拼接逻辑。

### 3. 复习反馈最后一环（pending-review → review）

之前的状态：cron 推了复习题，主人回 "4"，但 **Agent 不会自动调 digest review** 更新数据库 → SM-2 间隔不会调整 → 闭环不闭。

**补丁**：

- 新命令 `digest pending-review`：查最近 24h 推过但未答的 push_history 记录
- 新命令 `digest review <id> <q>`：SM-2 更新 items + 标记 push_history.response_quality
- SOUL.md 新增"处理复习应答"章节，引导 Agent：
  ```
  上一条消息是复习推送 + 主人回数字 1-5 或文字 →
    digest pending-review → 拿到 item_id →
    判断 quality（数字直接用 / 文字按映射表）→
    digest review <item_id> <quality>
  ```

**实测**：

```
复习前 id=3 状态：
  review_count=0, mastery=0, ease=2.5
  next_review_at=2026-05-12T19:00

主人回 "4"（quality=4）后：
  review_count=1, mastery=15, ease=2.65
  next_review_at=2026-05-16T01:30（约 3 天后）

再调 pending-review 返回 count=0 ← 已答过的不再 pending
```

至此**主动推送→回答→间隔调整**闭环成立。

详见 [[../docs/06-复习系统#反馈回写]]。

### 4. 手动 tier 调整（promote/demote/archive/view）

之前 DeepSeek 评分严苛，量化视频 8 千字给了 40 分（C 级）→ 不进复习队列。但主人觉得这条值得复习。

**新命令**：

```bash
digest view <id>                # 看详细
digest promote <id>             # 默认推到 A + 启动复习（明天开始）
digest promote <id> --tier B    # 推到指定 tier
digest promote <id> --weight 88 # 同时调权重
digest demote <id>              # 推到 C，停止推送
digest demote <id> --tier B     # 降到 B 但保留复习
digest demote <id> --archive    # 彻底归档（查询/推送都看不到）
```

SOUL.md 加规则让主人在飞书直接说"提到 A"、"降到 C"、"归档"，Agent 自动调对应命令。

**实测**：

```
C(40) → promote → A(95)，next_review=明天 8:30 ✅
A(95) → demote --tier B → B(75)，继续复习 ✅
B(75) → demote --archive → 归档（查询/推送都看不到）✅
还原 → archived=0 → promote → A(95) ✅
```

详见 [[../docs/08-命令速查#手动调级类]]。

### 5. HERMES_MAX_ITERATIONS 调高（90 → 180）

**问题**：8 分钟的抖音长视频 pipeline 跑到一半超时（whisper 转录耗时长 + 5 步 LLM 调用 + 9 步以上 turn），90 turn 上限不够。

**修复**：
1. `.env` 文件改 `HERMES_MAX_ITERATIONS=180`
2. systemd unit 加 `EnvironmentFile=-/root/.hermes/profiles/knowledge/.env`，让 systemd 启动就注入（而不是只靠 hermes 内部 dotenv override）
3. 验证 `/proc/<pid>/environ` 真的有 `HERMES_MAX_ITERATIONS=180`

详见 [[../docs/07-Hermes-Skill链路]]。

### 6. 周报 cron（每周日 22:00）

**新脚本** `weekly_report.py`：

汇总过去 7 天：
- 收录数 + tier 分布
- Top 3 高 weight 内容
- 关注主题（top 5 大类）
- 高频标签（top 8）
- 复习情况（推送数 / 应答率 / 平均质量）
- 全库掌握度
- 当前积压
- **AI 观察**（DeepSeek 看数据生成 3-4 句话）

**crontab**：

```cron
# 周日北京时间 22:00 = UTC 周日 14:00
0 14 * * 0 /usr/local/bin/weekly-report >> /var/log/weekly_report.log 2>&1
```

**同周去重**：用 `push_history.mode='weekly'` 标记，再调返回 skip。`--force` 可强制重发。

**实测样例**：

```
📊 本周知识周报
(2026-05-06 ~ 2026-05-13)

📥 本周收录 4 条 · 平均 66.8/100
  A 级 3 / C 级 1

🏆 Top 高价值
  1. [95·A] Hermes记忆详解，四层架构一次讲透 (id=3)
  2. [95·A] AI干货分享-AI炒股 (id=5)
  3. [92·A] 精讲OpenSpec... (id=6)

📂 关注主题
  AI(4) / 生产力(2) / 投资(2)

💡 AI 观察
  这周你聚焦在 AI、生产力和投资三个方向，A 级条目占比 75%，
  筛选意识在增强。下周建议重点消化"Hermes 记忆详解"...
```

## 主线闭环最终形态

```
你刷到 → 飞书发 → 5 步 pipeline → md + SQLite 落盘
                                      ↓
                            cron 每天 3 次主动推复习
                                      ↓
                                你回 1-5 分
                                      ↓
                          digest pending-review → review
                                      ↓
                            SM-2 更新 next_review_at
                                      ↓
                        每周日 22:00 自动汇总周报 + AI 观察
```

**从"信息垃圾桶"进化成"会主动找你、会看脸色、会复盘的助理"。**
